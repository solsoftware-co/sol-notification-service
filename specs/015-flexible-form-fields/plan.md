# Implementation Plan: Flexible Form Notification Fields

**Branch**: `015-flexible-form-fields` | **Date**: 2026-04-11 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/015-flexible-form-fields/spec.md`

## Summary

Make only `clientId` required in the `form/submitted` event payload. The previously required fields (`submitterName`, `submitterEmail`, `submitterMessage`) become optional. Three new standard optional fields are added (`submittedFrom`, `submitterPhone`, `formName`) along with a `customFields` escape hatch for arbitrary key-value data. The email template conditionally renders only fields that are present. `formId` is deprecated and silently ignored. No new packages, no database changes, no new infrastructure.

## Implementation Detail by File

### 1. `src/types/index.ts`

Replace the `FormSubmittedPayload` interface:

```typescript
export interface FormSubmittedPayload extends BaseEventPayload {
  // Previously required — now optional for backward compatibility
  submitterName?: string;
  submitterEmail?: string;
  submitterMessage?: string;
  // New standard optional fields
  submitterPhone?: string;
  submittedFrom?: string;
  formName?: string;
  customFields?: Record<string, string>;
  /** @deprecated Use formName instead. Silently ignored by the notification service. */
  formId?: string;
}
```

### 3. `src/lib/templates.ts` — `renderFormNotificationEmail()`

Rewrite the function body to:

1. Build `subject` using `formName` (not `formId`).
2. Pass all new fields to `SalesLeadV1Email`:
   - `customerName` ← `payload.submitterName`
   - `customerEmail` ← `payload.submitterEmail`
   - `comments` ← `payload.submitterMessage`
   - `customerPhone` ← `payload.submitterPhone`
   - `sourcePageLink` ← `payload.submittedFrom`
   - `sourcePageText` ← `payload.submittedFrom` (same value; template renders it as the link text)
   - `interestedIn` ← `payload.formName`
   - `customFields` ← `payload.customFields` (new prop to be added to the template)
3. Build `previewText` defensively: use name if present, fall back to email, fall back to generic.

```typescript
const subject = payload.formName
  ? `New form submission: ${payload.formName} — ${client.name}`
  : `New inquiry — ${client.name}`;

const previewText = payload.submitterName
  ? `New inquiry from ${payload.submitterName}`
  : payload.submitterEmail
  ? `New inquiry from ${payload.submitterEmail}`
  : `New inquiry — ${client.name}`;
```

### 4. `src/emails/templates/sales-lead-v1.tsx`

Four changes:

**a) Update `InquiryEmailProps`** — make previously required props optional, add `customFields`:

```typescript
export type InquiryEmailProps = {
    previewText: string;
    subheader: string;
    header: string;
    customerName?: string;        // was required
    customerEmail?: string;       // was required
    comments?: string;            // was required
    submittedAt: string;
    customerPhone?: string;
    interestedIn?: string;
    sourcePageText?: string;
    sourcePageLink?: string;
    logText?: string;
    logLink?: string;
    customFields?: Record<string, string>;  // new
};
```

**b) Build `fields` array conditionally**:

```typescript
const standardFields = [
    ...(customerName  ? [{ label: 'Name',  value: customerName }] : []),
    ...(customerEmail ? [{ label: 'Email', value: customerEmail, href: `mailto:${customerEmail}` }] : []),
    ...(customerPhone ? [{ label: 'Phone', value: customerPhone, href: `tel:${customerPhone}` }] : []),
    ...(interestedIn  ? [{ label: 'Interested In', value: interestedIn }] : []),
];

const customEntries = customFields
    ? Object.entries(customFields).filter(([, v]) => v !== '').map(([k, v]) => ({ label: k, value: v }))
    : [];

const fields = [...standardFields, ...customEntries];
```

**c) Guard the FieldGroup render** — only render if `fields.length > 0`:

```tsx
{fields.length > 0 && <FieldGroup fields={fields} />}
```

**d) Make the CTA button conditional** — only render when `customerEmail` is present:

```tsx
{customerEmail && (
    <CTAButton
        href={`mailto:${customerEmail}`}
        label={customerName ? `Reply to ${customerName}` : 'Reply'}
        variant="black"
        size="lg"
        radius="rounded"
    />
)}
```
